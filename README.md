# Tomato Timer

Приложение для управления временем по методу "Помидора" (Pomodoro Technique).

![Tomato Timer](src/img/svg/noto_tomato.svg)

## Описание

Tomato Timer — это инструмент для повышения продуктивности на основе техники Pomodoro. Приложение помогает организовать работу в цикличных интервалах: 25 минут работы, затем короткий перерыв (5 минут). После четырех рабочих циклов предоставляется более длительный перерыв (15 минут).

## Возможности

- Создание и управление списком задач
- Установка приоритета задач (низкий, средний, высокий)
- Таймер для отслеживания рабочих циклов и перерывов
- Автоматический расчет общего времени выполнения задач
- Сохранение задач между сессиями в localStorage браузера
- Возможность редактирования и удаления задач

## Как использовать

### Управление задачами

1. **Добавление задачи**:
   - Введите название задачи в поле ввода
   - Выберите приоритет, нажав на круглую кнопку рядом с полем ввода:
     - Зеленый (по умолчанию) - низкий приоритет
     - Желтый - средний приоритет
     - Красный - высокий приоритет
   - Нажмите кнопку "Добавить"

2. **Редактирование задачи**:
   - Нажмите на кнопку с тремя точками справа от задачи
   - В появившемся меню выберите "Редактировать"
   - Форма ввода перейдет в режим редактирования (появится соответствующее уведомление)
   - Измените название и/или приоритет задачи
   - Нажмите "Сохранить" для применения изменений или "Отмена" для отмены

3. **Удаление задачи**:
   - Нажмите на кнопку с тремя точками справа от задачи
   - В появившемся меню выберите "Удалить"
   - Подтвердите удаление в появившемся модальном окне

4. **Выбор активной задачи**:
   - Кликните на название задачи, чтобы сделать ее активной
   - Активная задача отображается в верхней панели таймера

### Использование таймера

1. **Запуск таймера**:
   - Выберите задачу из списка (она станет активной)
   - Нажмите кнопку "Старт" для запуска таймера
   - Работайте над задачей, пока таймер не завершится

2. **Остановка таймера**:
   - Нажмите кнопку "Стоп", чтобы приостановить таймер
   - Нажмите "Старт", чтобы продолжить отсчет

3. **Циклы работы**:
   - По завершении 25-минутного рабочего периода появится уведомление
   - После этого начнется 5-минутный перерыв
   - После каждых 4 циклов будет предоставлен длительный перерыв в 15 минут

## Структура проекта

- `src/` - исходный код проекта
  - `js/` - JavaScript файлы
  - `scss/` - стили в формате SCSS
  - `img/` - изображения и иконки
  - `fonts/` - шрифты
- `dist/` - скомпилированная версия для использования

## Технические детали

- Приложение использует Webpack для сборки
- Для стилизации используется SCSS
- Данные сохраняются в localStorage браузера
- Приложение работает полностью на клиентской стороне

## Как собрать проект

1. Убедитесь, что у вас установлен Node.js
2. Установите зависимости: `npm install`
3. Запустите сборку: `npm run build`
4. Для разработки используйте: `npm run dev`

## Известные особенности

- При редактировании задачи обратите внимание, что форма переходит в режим редактирования (появляется красная плашка "Режим редактирования")
- Активная задача выделяется и ее название отображается в панели таймера
- Общее расчетное время выполнения всех задач отображается внизу списка задач

## Использование в готовом виде

Для использования готового приложения просто откройте файл `dist/index.html` в браузере.
